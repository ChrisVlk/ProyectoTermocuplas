PROYECTO TERMOCUPLAS - EXPLICACION COMPLETA

1) OBJETIVO DEL PROYECTO
Este proyecto convierte valores de termocuplas usando tablas reales:
- mV -> temperatura (C)
- temperatura (C) -> mV

Soporta tres tipos de termocuplas: K, J y T.
Incluye offset de calibracion e historial de conversiones en sesion.


2) ARQUITECTURA GENERAL
El sistema es una aplicacion de escritorio escrita 100% en Prolog.
Usa la libreria grafica XPCE para la interfaz visual y la libreria CSV
para leer las tablas de referencia.

Archivo principal: Proyecto.pl

El programa se divide internamente en 3 bloques:
- Bloque 1: Interfaz grafica (ventana, campos, botones, historial)
- Bloque 2: Logica de la interfaz (calcular, limpiar, parseo, rutas)
- Bloque 3: Logica matematica (interpolacion lineal dual)


3) ARCHIVOS DEL PROYECTO
- Proyecto.pl          : codigo fuente completo (interfaz + logica + matematicas)
- Conversor.bat        : lanzador rapido (doble clic para abrir la app)
- tabla_k.txt          : tabla de referencia para termocupla Tipo K
- tabla_j.txt          : tabla de referencia para termocupla Tipo J
- tabla_t.txt          : tabla de referencia para termocupla Tipo T
- extraer_datos.py     : utilidad Python para generar las tablas desde PDF
- EXPLICACION_PROYECTO.txt : este archivo


4) COMO FUNCIONAN LAS TABLAS
Cada archivo de tabla contiene filas con el formato:
milivoltios,temperatura

Ejemplo:
10.153,250

El programa toma los dos puntos vecinos al valor ingresado y calcula
el resultado intermedio usando interpolacion lineal.


5) INTERFAZ GRAFICA
La ventana se organiza en paneles agrupados (dialog_group):

- "1. Configuracion del Sensor"
  Selector de tipo (K/J/T) y modo (mV a Grados / Grados a mV)

- "2. Entrada de Datos"
  Campo de valor numerico y campo de offset (lado a lado)

- "Resultado y Estado"
  Resultado en texto grande azul y mensaje de estado (verde=exito, rojo=error)

- Botones: CALCULAR, Limpiar

- "Historial de Conversiones"
  Lista que acumula todas las conversiones realizadas en la sesion

- Boton: Salir


6) LOGICA DE INTERPOLACION
Si tienes dos puntos (x1,y1) y (x2,y2), y un valor x entre ellos:
y = y1 + ((x - x1) / (x2 - x1)) * (y2 - y1)

En este proyecto:
- Para mV -> C: x es milivoltios, y es temperatura
- Para C -> mV: x es temperatura, y es milivoltios

Las filas se ordenan automaticamente antes de interpolar para evitar
errores cuando la tabla no esta en orden estricto.


7) OFFSET DE CALIBRACION
El offset es una correccion fija que se suma al resultado final.

Para que sirve:
- Corregir error sistematico del sensor o de la instalacion

Ejemplo:
- Si siempre mides 2 C menos de lo real, usa offset +2

Formula:
offset = valor_real - valor_medido


8) VALIDACION DE ENTRADA
El programa acepta numeros con punto o coma como separador decimal.
Si el usuario ingresa texto invalido, se muestra un mensaje de error
en rojo sin que el programa se cierre o falle.


9) HISTORIAL
Cada conversion exitosa o fallida se agrega a la lista de historial
dentro de la ventana. El historial se puede vaciar con el boton "Limpiar".
El historial es de sesion (se pierde al cerrar la app).


10) COMO EJECUTAR

Opcion A (rapida, recomendada):
1. Doble clic en Conversor.bat

Opcion B (manual desde terminal):
1. Abrir terminal en la carpeta del proyecto
2. Ejecutar:
   swipl
3. Dentro de Prolog:
   ?- consult('Proyecto.pl').
   ?- iniciar_app.

Requisito: Tener SWI-Prolog instalado en el sistema.


11) RESUMEN CORTO
Este proyecto usa Prolog con XPCE para resolver conversiones reales
de termocuplas (Tipo K, J y T) mediante interpolacion lineal, con una
interfaz de escritorio organizada en paneles, offset de calibracion
e historial de conversiones.
